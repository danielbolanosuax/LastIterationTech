# Changelog

All notable changes to God Mode Trading System will be documented in this file.

## [3.0.0] - 2026-02-06

### Added
- ✨ Sistema completo de trading algorítmico
- 🤖 15+ modelos de IA integrados
- 📊 Dashboard interactivo con Streamlit
- 🔔 Sistema de alertas (Email + Telegram)
- 💼 Paper trading con Alpaca
- 📈 Backtesting completo con métricas
- 🛡️ Risk management avanzado
- 💾 Cache de datos para optimizar API calls
- 📝 Documentación completa
- 🚀 Setup wizard automático

### Módulos de IA
- Temporal: ARIMA, GARCH, TFT, N-BEATS
- Visión: 1D-CNN, ResNet, YOLO
- Tabular: LightGBM, CatBoost
- NLP: FinBERT, GPT-4, NER
- Grafos: GCN, GAT
- RL: SAC (Soft Actor-Critic)
- Generative: TimeGAN

### Features
- Multi-model ensemble analysis
- Real-time market data (Alpha Vantage + Yahoo Finance)
- Automated position sizing (Kelly Criterion)
- Dynamic stop-loss and take-profit
- Portfolio management
- Signal tracking and logging
- Flexible configuration
- Production-ready architecture
